🤣 坑 #1：DeepSeek 手滑多敲了一个右括号 ]（v1.6.2 已焊死）

实弹测试第 2 轮时，大模型吐 JSON 手抖在结尾多敲了一个方括号，结果旧版解析器直接罢工，差点把整坨带秘密纸条的原始 JSON 全糊公屏上！后来连夜写了“三段式括号栈自愈修复器 + 零密语泄露兜底”，就算模型写歪也能把剧情和暗线 100% 抢救回来。

🤣 坑 #2：史诗大成功被“持枪”两个字吞了（v1.7.1 已焊死）

试玩掷出 [6, 6] + 2 = 14 满级侦查大成功，结果老雷恩一句“持枪戒备”撞上 KOOK 平台 40011 敏感词审核，整张卡片被拦截！现在加上了蒸汽奇幻词自动柔化重发 + 保底不断档交互卡 + /resend 一键补发，大成功一滴都不丢。

🤣 坑 #3：卡片越弹越多 + 陌生人名看到眼睛冒圈圈（v1.6.0 & v1.7.2 已重构）

最早开局、选职业、掷骰子、看角色卡全在公屏各自发新卡，聊天流碎得像补丁；后来先用 KOOK 原地编辑把公屏收束成纯净故事流，又干脆用 Cloudflare 隧道搭出 5 子页置顶悬浮 HUD 和交互式人物关系星图，终于清爽了！
